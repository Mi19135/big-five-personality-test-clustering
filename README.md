# big-five-personality-test-clustering
Data mining project exploring patterns in the Big Five Personality Test. Includes data preprocessing, PCA visualization, and clustering with multiple algorithms.

-data cleaning and preprocessing
-PCA and UMAP visualisation
-K-means
-Gaussian Mixture Model (GMM)
-Hierarchial (agglomerative) Clustering
-Spectral Clustering
-DBSCAN
-Cluster validation metrics

## Dataset 
The dataset used in this project was obtained from kaggle:
https://www.kaggle.com/datasets/tunguz/big-five-personality-test
